MagiKH Keyboard ជាកម្មវិធីក្ដារចុចខ្មែរថ្មី ឥតគិតថ្លៃ សម្រាប់ Windows 10 និង 11 (ចេញឆ្នាំ ២០២៦)។ កម្មវិធីក្ដារចុចនេះ ធ្វើឲ្យការវាយអក្សរខ្មែរលើកុំព្យូទ័រ លឿន និងងាយស្រួល៖ ក្នុង Auto Mode មិនចាំបាច់ចុច Shift, មិនចាំបាច់ដាក់ជើង (្) និងមានការទស្សទាយពាក្យ។ កូដអក្សរ គឺជា ខ្មែរយូនីកូដ ស្តង់ដារ។ MagiKH Keyboard is a new, free Khmer IME (Input Method Editor) or simply a Khmer keyboard software for Windows 10 and 11, released in 2026. It makes Khmer typing on Windows fast and simple — in Auto mode there is no Shift, no COENG (្), and it includes word prediction. The character code output is standard Khmer Unicode.

មុខងារ (ក្នុង Auto Mode — ស្វ័យប្រវត្តិ)Features (in Auto mode)

  • មិនចាំបាច់ចុច Shift No Shift
  • មិនចាំបាច់ចុច Alt+Ctrl No Alt+Ctrl
  • មិនចាំបាច់ដាក់ជើង ្ — ដាក់ដោយស្វ័យប្រវត្តិ No COENG sign ្ (ជើង) needed — added automatically
  • អាចទស្សទាយពាក្យ Word prediction
