Install & Setupដំឡើង និងរៀបចំ Keyboard Layoutប្លង់ក្តារចុច

System Requirements

🪟
Windows 10 or 11 64-bit only (x64)
🔑
Administrator rights Required during installation
🔤
Khmer OS or Khmer UI font Pre-installed on Windows 10/11

Installation

1

Run the installer

Double-click MagiKH_Keyboard_Setup.exe.

⚠️ Windows will show a User Account Control prompt asking for Administrator permission. Click Yes to allow — the installer needs it to register the keyboard with Windows.
2

Accept the license agreement

Read and accept the End-User License Agreement, then click Next.

3

Complete installation

Click Install. The installer will copy the keyboard file to C:\Program Files\MagiKH\ and register it with Windows automatically.

4

Sign out and sign back in

Click Finish, then sign out of Windows and sign back in (or restart your PC).

⚠️ This step is required. The keyboard will not appear in your language settings until you sign out and back in.

Setup — Add Khmer Keyboard

5

Open Language Settings

Go to:

Start › Settings › Time & Language › Language & Region
6

Add the Khmer language (if not installed)

If Khmer (Cambodia) is not in your language list, click Add a language, search for Khmer, select it and click Next → Install.

💡 You do not need to download optional Khmer language features (speech, handwriting). The keyboard alone is sufficient.
7

Open Khmer language options

In the language list, click the ⋯ (three-dot menu) next to Khmer (Cambodia) and choose Language options.

8

Add MagiKH Keyboard

Under Keyboards, click Add a keyboard and select MagiKH Keyboard from the list.

💡 If you don't see MagiKH Keyboard in the list, make sure you signed out and back in after installation.

Switching Input Method

Keyboard shortcut
Win + Space
Taskbar
Click the language indicator (e.g. ENG) in the system tray, then select Khmer — MagiKH
💡 Once MagiKH is active, look for the ម icon in the taskbar. You're ready to type in Khmer!

Uninstall

Go to Settings › Apps › Installed apps, search for MagiKH, click the ⋯ menu and choose Uninstall. The keyboard will be removed and unregistered automatically.

ការដំឡើង

១

ដំណើរការកម្មវិធីដំឡើង

ចុចទ្វេដង (double-click) លើ MagiKH_Keyboard_Setup.exe។

⚠️ Windows នឹងបង្ហាញប្រអប់ ការគ្រប់គ្រងគណនីអ្នកប្រើ (User Account Control) សុំសិទ្ធិ អ្នកគ្រប់គ្រង (Administrator)។ ចុច បាទ/ចាស (Yes) ដើម្បីអនុញ្ញាត — កម្មវិធីដំឡើងត្រូវការវាដើម្បីចុះបញ្ជីក្តារចុចជាមួយ Windows។
២

យល់ព្រមលើកិច្ចព្រមព្រៀងអាជ្ញាបណ្ណ

អាន និងយល់ព្រមលើ កិច្ចព្រមព្រៀងអាជ្ញាបណ្ណអ្នកប្រើ (End-User License Agreement) រួចចុច បន្ទាប់ (Next)។

៣

បញ្ចប់ការដំឡើង

ចុច ដំឡើង (Install)។ កម្មវិធីដំឡើងនឹងចម្លងឯកសារក្តារចុចទៅ C:\Program Files\MagiKH\ និងចុះបញ្ជីវាជាមួយ Windows ដោយស្វ័យប្រវត្តិ។

៤

ចាកចេញ រួចចូលប្រើឡើងវិញ

ចុច បញ្ចប់ (Finish) បន្ទាប់មកចាកចេញ (sign out) ពី Windows រួចចូលប្រើឡើងវិញ (ឬចាប់ផ្តើមកុំព្យូទ័រឡើងវិញ)។

⚠️ ជំហាននេះ ចាំបាច់។ ក្តារចុចនឹងមិនបង្ហាញក្នុងការកំណត់ភាសារបស់អ្នកទេ រហូតទាល់តែអ្នកចាកចេញ រួចចូលប្រើឡើងវិញ។

ការរៀបចំ — បន្ថែមក្តារចុចខ្មែរ

៥

បើកការកំណត់ភាសា

ចូលទៅកាន់៖

ចាប់ផ្តើម (Start) › ការកំណត់ (Settings) › ពេលវេលា និងភាសា (Time & Language) › ភាសា និងតំបន់ (Language & Region)
៦

បន្ថែមភាសាខ្មែរ (បើមិនទាន់មាន)

បើ ខ្មែរ (Cambodia) មិនមានក្នុងបញ្ជីភាសារបស់អ្នក ចុច បន្ថែមភាសា (Add a language) ស្វែងរក Khmer ជ្រើសរើសវា រួចចុច បន្ទាប់ (Next) → ដំឡើង (Install)។

💡 អ្នកមិនចាំបាច់ទាញយកមុខងារភាសាខ្មែរបន្ថែម (ការនិយាយ សំណេរដោយដៃ) ទេ។ ក្តារចុចតែមួយគឺគ្រប់គ្រាន់ហើយ។
៧

បើកជម្រើសភាសាខ្មែរ

ក្នុងបញ្ជីភាសា ចុចម៉ឺនុយ ⋯ (ចំណុចបី) នៅជាប់នឹង ខ្មែរ (Cambodia) រួចជ្រើសរើស ជម្រើសភាសា (Language options)។

៨

បន្ថែម MagiKH Keyboard

នៅក្រោម ក្តារចុច (Keyboards) ចុច បន្ថែមក្តារចុច (Add a keyboard) រួចជ្រើសរើស MagiKH Keyboard ពីបញ្ជី។

💡 បើអ្នកមិនឃើញ MagiKH Keyboard ក្នុងបញ្ជី សូមប្រាកដថាអ្នកបានចាកចេញ រួចចូលប្រើឡើងវិញ បន្ទាប់ពីការដំឡើង។

ការលុបចេញ

ចូលទៅ ការកំណត់ (Settings) › កម្មវិធី (Apps) › កម្មវិធីដែលបានដំឡើង (Installed apps) ស្វែងរក MagiKH ចុចម៉ឺនុយ ⋯ រួចជ្រើសរើស លុបចេញ (Uninstall)។ ក្តារចុចនឹងត្រូវលុប និងដកបញ្ជីចេញដោយស្វ័យប្រវត្តិ។
